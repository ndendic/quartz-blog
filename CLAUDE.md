# Blog

Personal blog exploring the intersection of philosophy, technology, and human potential.

## Purpose

Nikola's public writing platform. Theme: **"Create beauty in alignment with truth and goodness."** Content blends Jungian depth psychology, technology philosophy, and the builder's mindset.

## Folder Structure

| Path | Content |
|------|---------|
| **content/** | Quartz content directory |
| **quartz/** | Quartz framework |
| **backend/** | Sanic backend |
| **public/** | Static assets |
| **Board.md** | Kanban board for blog planning |
| **GUIDE.md** | Maintainer's guide |

## Platform

**Quartz/Nitro self-hosted**.

**Stack**: Quartz v4 (static gen) + Sanic (async server) + Datastar RC.8 (interactivity) + datastar-py (SSE SDK)
